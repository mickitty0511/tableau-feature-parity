## 機能の違い
この機能はTableau Cloudでのみ利用可能です。Tableau Cloudでは、テキスト編集モードでハイパーリンクを追加・変更し、表示名をカスタマイズすることができます。

- **Desktop**: 限定的なテキスト編集機能のみで、ハイパーリンクの編集機能は利用できません。
- **Cloud**: テキスト編集モードで包括的なハイパーリンク編集機能が利用でき、URLの設定と表示名の個別カスタマイズが可能です。

## 使い方
### Tableau Cloudの場合
テキストオブジェクトまたはテキストマークでハイパーリンクを管理できます。

#### ハイパーリンクの追加
1. ダッシュボードまたはワークシート上のテキストオブジェクトをダブルクリックしてテキスト編集モードに入ります。
2. ハイパーリンクを設定したいテキストを選択します。
3. テキスト編集ツールバーのハイパーリンクボタンをクリックします。
4. 「ハイパーリンクの挿入」ダイアログで以下を設定します：
   - **URL**: リンク先のウェブサイトアドレス
   - **表示テキスト**: ユーザーに表示されるテキスト（URLとは異なる名称に設定可能）
5. 「OK」をクリックして設定を適用します。

#### ハイパーリンクの変更
1. 既存のハイパーリンクテキストを選択します。
2. テキスト編集ツールバーのハイパーリンクボタンをクリックします。
3. 「ハイパーリンクの編集」ダイアログでURLまたは表示テキストを修正します。
4. 変更内容を保存します。

#### 表示名のカスタマイズ
1. ハイパーリンクの表示テキストを、実際のURL文字列とは独立してカスタマイズできます。
2. 例：URLが「https://www.example.com/very-long-complex-url」でも、表示テキストは「サンプルサイト」として設定可能。
3. これにより、ユーザーフレンドリーなテキスト表示を保ちながら適切なリンク機能を提供できます。

## 利用例
### 具体的な用途
- **ダッシュボードナビゲーション**: 関連するレポートやWebサイトへの直接リンク
- **参照情報の提供**: データソースや詳細説明への外部リンク
