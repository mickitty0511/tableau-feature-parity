# Advanced Workbook Control Commands

## Feature Differences
The availability of advanced workbook control commands differs between Tableau Desktop and Tableau Cloud.

- **Desktop**: Advanced workbook control commands are not available
- **Cloud**: The following advanced workbook control commands are available:
  - Add to Collection
  - Move
  - Edit Description
  - Permissions
  - Change Owner
  - Revision History
  - Edit Details
  - Move Location
  - View Revision History

## Usage Instructions

### Tableau Cloud Operations
1. Log in to Tableau Cloud and select a workbook.
2. Right-click on the workbook or open the options menu.
3. Select the required operation from the available advanced control commands.

![Workbook Information Screen](../jp/img/cloud/workbook_info_cloud_jp.png)

### Tableau Desktop Operations
These advanced workbook management features are not available in Tableau Desktop. Only basic file operations (Save, Save As, etc.) are possible.

## Usage Examples

### Collection Management
- Organize workbooks into specific collections
- Shared access management between teams

### Permission Management
- Detailed settings for workbook viewing and editing permissions
- Access control by department or project unit

### Version Management
- Review and manage revision history
- Compare and restore previous versions

### Metadata Management
- Edit workbook descriptions and tags
- Detailed information management for improved searchability

## Notes and Considerations

- These features are exclusive to Tableau Cloud and are not available in Tableau Desktop
- Advanced workbook management features enable enhanced control of metadata, permissions, and organizational functions
- Some operations may require appropriate permissions
- Consider feature usage according to organizational policies
