# ビューオプション

## 機能の違い

高度なビュー管理機能に関して、Tableau DesktopとTableau Cloudで大きな違いがあります。

- **Desktop**: 基本的なビュー機能のみが利用可能で、Cloudと同様の高度なビュー管理機能にはアクセスできません
- **Cloud**: 包括的なビューオプションが利用可能で、名前を付けて保存、共有、コメント、サブスクリプション、データドリブンアラート、ビューのリセットなどの高度な機能が提供されています

## 使用方法

### Tableau Desktop
Tableau Desktopでは、基本的なビュー機能のみが提供されており、Cloudで利用可能な高度なビューオプションにはアクセスできません。

### Tableau Cloud
Tableau Cloudでは、以下の高度なビューオプション機能が利用できます：

#### 1. ビューの変更
ビューの設定や表示オプションを変更できます。

![ビューの変更](./img/cloud/change_view_cloud_jp.png)

#### 2. コメント機能
ビューにコメントを追加・管理できます。

![コメント機能](./img/cloud/comment_cloud_jp.png)

#### 3. データドリブンアラート設定
データの変化に基づいて自動的にアラートを設定できます。

![データドリブンアラート設定](./img/cloud/data_driven_alert_settings_ui_cloud_jp.png)

#### 4. データドリブンアラートサブスクリプション
アラートの購読設定を管理できます。

![データドリブンアラートサブスクリプション](./img/cloud/data_driven_alert_subscription_cloud_jp.png)

#### 5. ビューのリセット
ビューを初期状態に戻すことができます。

![ビューのリセット](./img/cloud/reset_view_cloud_jp.png)

#### 6. 名前を付けて保存
ビューを新しい名前で保存できます。

![名前を付けて保存](./img/cloud/save_view_as_cloud_jp.png)

#### 7. ビューの共有
ビューを他のユーザーと共有できます。

![ビューの共有](./img/cloud/share_view_cloud_jp.png)

#### 8. サブスクリプション設定
ビューの定期更新や通知を設定できます。

![サブスクリプション設定](./img/cloud/subscription_settings_ui_cloud_jp.png)

## 利用例・用途

### Tableau Cloud での活用場面
- **協業**: コメント機能を使ったチーム内でのディスカッション
- **監視**: データドリブンアラートによる重要指標の自動監視
- **共有**: 特定のビュー設定を他のユーザーと共有
- **バックアップ**: 重要なビュー設定の保存とバージョン管理
- **通知**: サブスクリプション機能による定期レポートの自動配信

## 注意事項

- **Desktop**: 現在、Cloudで提供されている高度なビューオプション機能は利用できません
- **Cloud**: これらの機能はTableau Cloud専用の拡張機能です
- 今後のDesktopバージョンでの機能追加については未定です
- 各機能の詳細な設定オプションや制限事項については、今後の調査で追加予定です
- データドリブンアラートやサブスクリプション機能は、適切な権限設定が必要です
