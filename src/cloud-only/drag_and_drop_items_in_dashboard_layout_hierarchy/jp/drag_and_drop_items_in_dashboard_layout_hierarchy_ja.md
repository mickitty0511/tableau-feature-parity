## 機能の違い
この機能はTableau Cloudでのみ利用可能です。Tableau Cloudでは、ダッシュボードレイアウト階層内で項目を直接ドラッグアンドドロップして再配置することができます。

- **Desktop**: レイアウト階層での項目のドラッグアンドドロップ機能は利用できません。
- **Cloud**: レイアウト階層パネルで項目を自由にドラッグアンドドロップして再配置が可能です。

## 使い方
### Tableau Cloudの場合
1. ダッシュボードを編集モードで開きます。
2. 左側のレイアウトパネルでダッシュボード階層を表示します。
3. 移動したい項目（ワークシート、コンテナ、オブジェクトなど）をクリックして選択します。
4. 項目を目的の位置までドラッグして、適切な場所にドロップします。
5. レイアウト階層が即座に更新され、ダッシュボードのレイアウトが変更されます。

クラウド版の例：

![クラウド版](./img/cloud/moveable_items_dashboard_layout_cloud_jp.gif)

### Tableau Desktopの場合
Tableau Desktopでは、この機能は利用できません。レイアウト階層での直接的な項目移動はサポートされていません。

1. ダッシュボードでの項目の再配置は、ダッシュボード上で直接ドラッグアンドドロップする必要があります。
2. レイアウト階層パネルでは項目の表示と選択のみが可能です。
3. 複雑なレイアウト変更には手動での再配置が必要です。

## 利用例
### 具体的な用途
- **レイアウト構造の整理**: 複雑なダッシュボードで項目の階層を視覚的に整理
- **コンテナの管理**: 水平・垂直コンテナ内でのワークシートの順序変更
- **効率的なデザイン調整**: ドラッグアンドドロップによる直感的なレイアウト変更

### 推奨される使用場面
- 大規模なダッシュボードでの項目整理が必要な場合
- 複数のワークシートやオブジェクトの配置を頻繁に変更する場合
- レイアウト階層を視覚的に理解しながら設計したい場合
- プロトタイプ段階でのレイアウト検討が必要な場合

## 運用上の重要性
### ダッシュボードデザインへの影響
- **設計効率の向上**: 直感的な操作でレイアウト変更が可能
- **構造の可視化**: レイアウト階層を視覚的に理解しながら設計
- **保守性の向上**: 複雑なダッシュボードの構造管理が容易

### 業務への影響
- **時間短縮**: 手動での再配置作業が不要
- **エラー削減**: 視覚的な操作により配置ミスを防止
- **協働作業の改善**: チームメンバー間でのレイアウト意図の共有が容易

## 制約事項
### Desktop版での制約
- レイアウト階層でのドラッグアンドドロップ機能なし
- 項目の再配置はダッシュボード上での直接操作のみ
- 複雑な階層構造のメンテナンスに手間がかかる

### 注意事項
- この機能はダッシュボード設計の効率性に大きく影響するため、Cloud環境でのダッシュボード作成を推奨
- Desktop版では代替手段として、ダッシュボード上での直接的なドラッグアンドドロップを活用
- 複雑なレイアウトの場合、Cloud版での作業が効率的

## 備考
- この機能により、Tableau Cloudでのダッシュボード設計がより直感的で効率的になります。
- レイアウト階層の視覚的な管理は、特に大規模なダッシュボードにおいて重要です。
