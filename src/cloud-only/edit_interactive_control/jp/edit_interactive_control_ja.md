# インタラクティブコントロールの編集

## 機能の違い

インタラクティブコントロール機能の編集に関して、Tableau DesktopとTableau Cloudで大きな違いがあります。

- **Desktop**: インタラクティブコントロールの編集機能は利用できません
- **Cloud**: 高度なインタラクティブコントロールオプションが利用可能で、詳細な編集設定ができます

## 使用方法

### Tableau Desktop
Tableau Desktopでは、インタラクティブコントロールの編集機能は現在サポートされていません。

![Desktop表示例](./img/desktop/format_tab_desktop_jp.png)

### Tableau Cloud  
1. ダッシュボードまたはワークシートでインタラクティブコントロールを選択します
2. 編集オプションから詳細設定にアクセスします
3. 高度なインタラクティブコントロールオプションを設定できます

![Cloud表示例](./img/cloud/edit_interactive_control_cloud_jp.png)

## 利用例・用途

### Tableau Cloud での活用場面
- ダッシュボードのユーザーインタラクション向上
- 動的なフィルター操作の実装
- カスタムコントロール要素の作成
- ユーザビリティの向上

## 注意事項

- **Desktop**: 現在、インタラクティブコントロールの編集機能は提供されていません
- **Cloud**: この機能はTableau Cloud専用の拡張機能です
- 今後のDesktopバージョンでの機能追加については未定です
- Cloudでの詳細な設定オプションや制限事項は、今後の調査で追加予定です
