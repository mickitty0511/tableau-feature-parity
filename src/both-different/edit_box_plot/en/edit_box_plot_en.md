# Box Plot

## Feature Differences
The box plot functionality interface and options differ between Tableau Desktop and Cloud.

- **Desktop**: Available in Analytics pane with both Summary and Custom display options. More detailed formatting and context menu options are available
- **Cloud**: Available in Analytics pane with Summary option only. Context menu provides only delete functionality.

## Usage Instructions
### Tableau Desktop
1. Select Analytics pane > Box Plot
2. Right-click to access detailed settings such as formatting from the context menu

![Desktop Box Plot](../jp/img/desktop/edit_box_plot_desktop_jp.png)

### Tableau Cloud
1. Select Analytics pane > Box Plot
2. Right-click to access only the delete command from the context menu

![Cloud Box Plot](../jp/img/cloud/edit_box_plot_cloud_jp.png)

## Notes and Considerations
- Desktop version allows detailed formatting settings such as color configuration, while Cloud version is limited to delete functionality only
- Box plot options are displayed as Summary and Custom in Desktop, but only Summary is available in Cloud.
