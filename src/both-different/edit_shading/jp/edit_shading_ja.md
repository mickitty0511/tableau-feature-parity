## 機能の違い
Tableau DesktopとCloudでは、網掛け設定UIのインターフェースが異なります。

- **Desktop**: より詳細な設定オプションが利用可能
- **Cloud**: 簡略化された設定インターフェース

## 使用方法
### Tableau Desktop
1. 書式設定(タブ) > 網掛け
2. 縞模様オプションは常に有効化されている。色を設定しない場合は「なし」に指定。

![Desktop版の網掛け設定](./img/desktop/edit_shading_desktop_jp.png)

### Tableau Cloud
1. ワークシート編集画面にて、書式設定 > ワークシート
2. 網掛けセクションにアクセス
3. 縞模様オプションが有効/無効化ボタンで切り替え ※初期状態は無効済み
4. 色を設定しない場合はボタンで無効化へ

![Cloud版の網掛け設定](./img/cloud/edit_shading_cloud_jp.png)
