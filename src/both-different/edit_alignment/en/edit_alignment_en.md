# Alignment Settings UI

## Feature Differences

The alignment settings UI interface differs between Tableau Desktop and Tableau Cloud.

- **Desktop**: Alignment tab is provided separately in formatting settings
- **Cloud**: Alignment settings are integrated within font settings in formatting

## Usage Instructions

### Tableau Desktop
1. Access alignment settings in the formatting panel
2. Configure alignment options using the traditional interface

![Alignment Settings UI (Desktop)](../jp/img/desktop/edit_alignment_desktop_jp.png)

### Tableau Cloud
1. Access font settings from the worksheet formatting tab
2. Configure alignment options from header and other settings

![Alignment Settings UI (Cloud)](../jp/img/cloud/edit_alignment_cloud_jp.gif)

## Considerations and Limitations

- **Desktop**: Alignment settings are separate from font settings, keeping the configuration compact
- **Cloud**: Integration into font settings increases the amount of information in font configuration, making it less user-friendly for Desktop users
