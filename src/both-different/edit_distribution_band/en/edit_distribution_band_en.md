# Distribution Band

## Feature Differences

The distribution band functionality differs between Tableau Desktop and Tableau Cloud.

- **Desktop**: Full distribution band options are available
- **Cloud**: Limited distribution band functionality

## Usage Instructions

### Tableau Desktop
1. Right-click on the distribution band in the worksheet
2. Access options to change formatting and display position (front/back)

![Distribution Band Context Menu Options (Desktop)](../jp/img/desktop/edit_distribution_band_context_menu_desktop_jp.png)

![Distribution Band Settings UI (Desktop)](../jp/img/desktop/edit_distribution_band_settings_desktop_jp.png)

### Tableau Cloud
1. Right-click on the distribution band in the worksheet
2. Settings can be changed in the edit screen, but options are more limited than Desktop

![Distribution Band Context Menu Options (Cloud)](../jp/img/cloud/edit_distribution_band_context_menu_cloud_jp.png)

![Distribution Band Settings UI (Cloud)](../jp/img/cloud/edit_distribution_band_settings_cloud_jp.png)

## Notes and Considerations

- **Desktop**: Full distribution band options are available with detailed settings and customization capabilities
- **Cloud**: Distribution band formatting options such as color are limited, with only some options available
