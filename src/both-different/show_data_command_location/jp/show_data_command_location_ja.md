## 機能の違い
データ表示コマンドへのアクセス場所が、Tableau DesktopとTableau Cloudで異なります。

- **Desktop**: ワークシートのビュー(キャンバス)の空白部分のコンテキストメニュー、選択データのコンテキストメニュー、データペーン検索右側、「データ」タブ > [各データソース名] > 「データの表示」、データペイン内データソースのコンテキストメニュー、分析タブ 
- **Cloud**: ワークシートのビュー空白部分のコンテキストメニュー、選択データのコンテキストメニューのみ

## 使用方法
### Tableau Desktop
複数の方法でデータ表示コマンドにアクセスできます：

方法1: ワークシートのビューの空白部分から
1. ワークシートの空白部分を右クリックします
2. コンテキストメニューから「データの表示」を選択します

![Desktop ワークシート空白コンテキストメニュー](./img/desktop/ビュー内の空白部分から_desktop_jp.png)

方法2: 選択データから
1. 表示したいデータを選択します
2. 右クリックしてコンテキストメニューから「データの表示」を選択します

![Desktop 選択データコンテキストメニュー](./img/desktop/データを選択後_desktop_jp.png)

方法3: データペーン検索エリアから
1. データペーンの検索ボックス右側のアイコンをクリックします
![Desktop データペーン検索右側](./img/desktop/データペーンの検索欄の右横のアイコンから_jp.png)

方法4: データタブから
1. 「データ」タブをクリック
2. 対象のデータソースを選択し、「データの表示」をクリックします
![Desktop データメニューからのアクセス](./img/desktop/データタブの各データソースから_jp.png)

方法5: データソースコンテキストメニューから
1. データペイン内のデータソース名を右クリックします
2. コンテキストメニューから「データの表示」を選択します
![Desktop データソースコンテキストメニュー](./img/desktop/データペーン上の各データソースから_jp.png)

方法6: 分析タブから
1. 「分析」タブをクリックします
2. 「データの表示」をクリックします
![Desktop 分析タブからのアクセス](./img/desktop/分析タブから_jp.png)


### Tableau Cloud
限定的な方法でのみアクセス可能です：

方法1: ワークシートのビューの空白部分から
1. ワークシートのビュー内の空白部分を右クリックします
2. コンテキストメニューから「データの表示」を選択します
![Cloud ワークシート空白コンテキストメニュー](./img/cloud/ビュー内の空白部分から_cloud_jp.png)

方法2: 選択データから
1. 表示したいデータを選択します
2. 右クリックしてコンテキストメニューから「データの表示」を選択します
![Cloud 選択データコンテキストメニュー](./img/cloud/データを選択後_cloud_jp.png)

## 注意事項
- Desktopでは、6つの異なる方法でデータ表示コマンドにアクセスできます
- Cloudでは、コンテキストメニューを使用した2つの方法のみ利用可能です
- データペーン検索エリア、データタブ、データソースコンテキストメニュー、分析タブからのアクセスはCloudでは利用できません

- データ品質チェック
