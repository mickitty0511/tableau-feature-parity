## 機能の違い
パブリッシュ時に選択したプロジェクト内のワークブックを一覧表示・選択（簡単上書き）機能は、Tableau Desktopでのみ利用可能です。

- **Desktop**: パブリッシュダイアログで選択したプロジェクト内の既存ワークブックが一覧表示され、上書きしたいワークブックを簡単に選択できます。
- **Cloud**: 基本的なパブリッシュダイアログのみで、プロジェクト内のワークブック一覧表示機能はありません。

## 使用方法
### Tableau Desktop
1. ワークブックを開いた状態で、「サーバー」→「パブリッシュ」または「ファイル」→「パブリッシュ」を選択します。
2. パブリッシュダイアログでプロジェクトを選択します。
3. 選択したプロジェクト内の既存ワークブック一覧が表示されます。
4. 上書きしたいワークブックを一覧から選択できます。

![Desktop でのワークブック選択機能](./img/desktop/workbook_selection_publish_desktop_jp.gif)

### Tableau Cloud
1. ワークブックを開いた状態で、パブリッシュオプションを選択します。
2. 基本的なパブリッシュダイアログが表示されます。
3. プロジェクト内のワークブック一覧表示機能はありません。

![Cloud での基本パブリッシュダイアログ](./img/cloud/basic_publish_dialog_cloud_jp.gif)

## 利用例・ユースケース
- 同じプロジェクト内に複数のワークブックがある場合の上書きパブリッシュ
- 既存ワークブックの確認と選択による意図しない上書きの防止
- プロジェクト管理における効率的なワークブック更新作業

## 注意点・考慮事項
- この機能はTableau Desktopでのみ利用可能で、運用上重要な機能です。
- Cloudでは手動でワークブック名を入力するか、既存のワークブック名を覚えておく必要があります。
- 大規模なプロジェクトでワークブックを管理する際に、Desktopの方が効率的です。
- 将来的にCloudでもこの機能が追加される可能性があります。

## 現在の制限
- Tableau Cloudでは、プロジェクト内の既存ワークブック一覧を参照することができません。
- 上書きパブリッシュの際は、正確なワークブック名を手動で入力する必要があります。
