## 機能の違い
カスタムテーマのインポート機能は、Tableau Desktop（バージョン2025.1以降）でのみ利用可能です。

- **Desktop**: 書式設定メニューからカスタムテーマファイルをインポートして、パーソナライズされた視覚化スタイルを適用できます。
- **Cloud**: カスタムテーマのインポート機能は利用できません。

## 使用方法
### Tableau Desktopでの操作手順
1. Tableau Desktopでワークブックを開きます。
2. メニューバーの「書式設定」をクリックします。
3. 「ワークブックテーマ」にマウスを移動します。
4. 「カスタムテーマのインポート...」を選択します。

![カスタムテーマインポートメニュー](./img/desktop/custom_theme_import_menu_desktop_jp.png)

5. ファイルダイアログからカスタムテーマファイル（.tps形式）を選択します。
6. インポートが完了すると、選択したカスタムテーマがワークブックに適用されます。

### Tableau Cloudでの制限
Tableau Cloudでは、カスタムテーマのインポート機能は提供されていません。既存のビルトインテーマのみ使用可能です。

## 使用例・活用場面
- **企業ブランディング**: 会社のブランドカラーやフォントを反映したテーマの適用
- **一貫したデザイン**: 複数のワークブック間で統一されたデザインの維持
- **カスタマイズされた視覚化**: 特定の用途や業界に特化したテーマの作成と適用

## 注意事項と考慮点
- この機能はTableau Desktop 2025.1以降でのみ利用可能です。
- カスタムテーマファイルは.tps形式である必要があります。
- インポートしたテーマは、そのワークブックにのみ適用されます。
- Tableau Cloudでワークブックを公開する際、カスタムテーマの設定は保持されますが、新しいカスタムテーマのインポートはできません。
- 今後のバージョンでTableau Cloudでもこの機能が提供される可能性があります。
