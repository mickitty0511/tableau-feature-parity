## Feature Differences
The context menu available for string fields in the data source pane is only available in Tableau Desktop.

- **Desktop**: Various context menu options are displayed when right-clicking on string fields
- **Cloud**: Context menus for string fields only have basic options available

## Usage Instructions
### Tableau Desktop
1. Select a string field in the data source pane
2. Right-click the field to display the context menu
3. Select the required operation from the extended menu options displayed

Desktop example:

![Desktop Extended Context Menu](./img/desktop/extended_context_menu_desktop_jp.png)

### Tableau Cloud
1. Select a string field in the data source pane
2. Right-click the field to display the context menu
3. Only basic menu options are available

Cloud example:

![Cloud Basic Context Menu](./img/cloud/basic_context_menu_cloud_jp.png)

## Use Cases and Applications
- **Data Type Changes**: Desktop provides rich options when changing field data types
- **Field Settings**: Desktop offers more choices when modifying field attributes and settings
- **Data Operations**: Various operations on string fields are possible in Desktop

## Notes and Considerations
- Desktop provides more context menu options for string fields
- Cloud only provides basic options, and some advanced operations are not available
- Consider using Desktop when performing complex data operations
- Future updates may expand functionality in Cloud
