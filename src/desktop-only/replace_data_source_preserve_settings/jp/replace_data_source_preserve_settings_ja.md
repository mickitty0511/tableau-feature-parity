## 機能の違い
ソートと色の設定を継承するデータソース置換コマンドは、Tableau Desktopでのみ利用可能です。

- **Desktop**: データソースを置換する際に、ソート順や色の設定を継承することができます。
- **Cloud**: この機能は利用できません。

## 使用方法
### Tableau Desktop
1. ワークブックでデータソースを使用している状態で、データペインのデータソースを右クリックします。
2. コンテキストメニューから「データソースの置換」を選択します。
3. 置換先のデータソースを選択します。
4. 置換時に、既存のソート設定や色の設定が新しいデータソースに自動的に継承されます。

![データソース置換メニュー（Desktop）](./img/desktop/replace_data_source_preserve_settings_desktop_jp.png)

### Tableau Cloud
この機能はTableau Cloudでは利用できません。

## 使用例・活用場面
- 開発環境から本番環境への移行時に、ビューの設定を保持したままデータソースを切り替える場合
- 同じ構造の別のデータソースに切り替える際に、既存の色分けやソート設定を維持したい場合
- データソースの接続先を変更する際に、ダッシュボードの見た目を保持したい場合

## 注意点・考慮事項
- この機能はTableau Desktopの固有機能であり、Tableau Cloudでは利用できません。
- データソース置換時に、フィールド名や構造が異なる場合は、設定が正常に継承されない可能性があります。
- 複雑な計算フィールドや階層構造がある場合は、置換後に設定の確認が必要です。
- この機能は運用上重要な機能として分類されており、ワークブック編集機能に大きく影響します。

## 今後の展望
現時点では、この機能のTableau Cloudでの対応予定については情報がありません。
