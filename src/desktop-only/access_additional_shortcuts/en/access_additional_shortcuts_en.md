# Tableau Keyboard Shortcuts Comparison

This document compares keyboard shortcuts between Tableau Cloud and Tableau Desktop for both Windows and Mac. Each shortcut is categorized according to the official sections from [Tableau Help](https://help.tableau.com/current/pro/desktop/ja-jp/shortcut.htm).
