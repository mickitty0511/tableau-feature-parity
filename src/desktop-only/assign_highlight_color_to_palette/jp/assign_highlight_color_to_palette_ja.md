## 機能の違い
レジェンドから「選択したアイテムをハイライト」を有効にする際に、ハイライト色をパレットに割り当てるオプションは、Tableau Desktop でのみ利用可能です。

- **Desktop**: レジェンドのコンテキストメニューに「ハイライト色をパレット割り当てる」オプションが存在し、ハイライト機能使用時の色の管理をより細かく制御できます。
- **Cloud**: このオプションは利用できません。基本的なハイライト機能のみ利用可能です。

## 使用方法
### Tableau Desktop の場合
1. ワークシートでレジェンドを右クリックします。
2. コンテキストメニューから「選択したアイテムをハイライト」を選択します。
3. 「ハイライト色をパレット割り当てる」オプションを選択して、ハイライト時の色をカスタマイズします。

Desktop での表示例:
![Desktop でのハイライト色オプション](./img/desktop/highlight_color_option_desktop_jp.png)

### Tableau Cloud の場合
1. ワークシートでレジェンドを右クリックします。
2. コンテキストメニューから「選択したアイテムをハイライト」を選択できますが、ハイライト色の詳細設定オプションは利用できません。

Cloud での表示例:
![Cloud でのハイライト色オプション](./img/cloud/highlight_color_option_cloud_jp.png)

## 利用例・使用場面
- **データの視覚的強調**: 特定のカテゴリやデータポイントを強調表示する際に、色の一貫性を保ちたい場合
- **ダッシュボードの統一感**: 複数のビューで同じハイライト色を使用して、統一されたビジュアルデザインを維持したい場合
- **プレゼンテーション**: 特定のデータを聴衆に注目してもらいたい際の色の制御

## 注意点・考慮事項
- Desktop では、ハイライト色をパレットに割り当てることで、より詳細な色の制御が可能です。
- Cloud では、標準のハイライト機能のみ利用可能で、色のカスタマイズは制限されています。
- この機能は「operationally-critical」としてラベル付けされており、ワークブック編集機能に重要な影響を与える可能性があります。
- 将来的に Cloud でもこの機能が利用可能になる可能性があります。
