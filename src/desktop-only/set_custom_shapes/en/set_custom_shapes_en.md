## Feature Differences
Custom shapes functionality is only available in Tableau Desktop.

- **Desktop**: You can import custom shape files and use unique shapes in visualizations
- **Cloud**: Only default shapes are available

## Usage Instructions
### Tableau Desktop
1. Select shapes in the Marks panel
2. Choose "Custom Shapes" option from the shape palette
3. Import custom shape files (.png, .jpg, etc.)
4. Apply imported shapes to visualizations

![Custom Shapes Available in Desktop](../jp/img/desktop/set_custom_shapes_desktop_jp.png)

### Tableau Cloud
1. Select shapes in the Marks panel
2. Only default shapes are available
3. Custom shape import functionality is not available

![Limited Shape Options in Cloud](../jp/img/cloud/limited_shapes_cloud_jp.gif)

## Use Cases and Applications
- Visualizations using corporate logos and icons
- Professional dashboards using industry-specific shapes
- Customized visualizations aligned with branding
- Custom marker displays on maps

## Notes and Limitations
- Custom shapes functionality is only available in Desktop
- Only default shapes are available in Cloud
- When displaying workbooks created in Desktop with custom shapes in Cloud, shapes may not display correctly
- Supported file formats: PNG, JPEG, GIF, BMP, etc.

## Future Outlook
Currently, no specific plans for custom shape support in Cloud environments have been announced.
