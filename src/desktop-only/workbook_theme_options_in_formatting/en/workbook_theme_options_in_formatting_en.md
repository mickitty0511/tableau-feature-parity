## Feature Differences
Workbook theme options in formatting are only available in Tableau Desktop.

- **Desktop**: Workbook theme options are available in formatting, allowing consistent design application.
- **Cloud**: Workbook theme options are not available.

## Usage Instructions
### Tableau Desktop
1. In a worksheet or dashboard, access the formatting menu.
2. Select a preset theme from the workbook theme options.
3. The selected theme is applied to the entire workbook, achieving consistent design.

![Desktop Workbook Theme Options](./img/desktop/workbook_theme_options_desktop_jp.png)

### Tableau Cloud
1. Access the formatting menu.
2. Only basic formatting options are available; workbook theme options are not displayed.

![Cloud Basic Workbook Formatting](./img/cloud/basic_workbook_formatting_cloud_jp.png)

## Use Cases and Applications
- **Corporate Branding**: When creating workbooks with unified company colors and fonts
- **Report Consistency**: When maintaining consistent design across multiple worksheets and dashboards
- **Presentation Use**: When creating visually unified presentation materials

## Notes and Limitations
- This functionality is only available in Tableau Desktop and is not provided in Tableau Cloud.
- Applying workbook themes may overwrite existing individual formatting settings.
- Creating and importing custom themes requires additional Desktop functionality.
