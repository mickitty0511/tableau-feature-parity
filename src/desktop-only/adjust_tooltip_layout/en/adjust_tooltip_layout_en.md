## Feature Differences
Slider and ruler functionality in tooltips for field arrangement is only available in Tableau Desktop.

- **Desktop**: When editing tooltips, sliders and rulers are available for precise field arrangement adjustment.
- **Cloud**: Slider and ruler functionality is not available in tooltip editing.

## Usage Instructions
### Tableau Desktop
1. Click "Tooltip" on the marks card in a worksheet.
2. The tooltip editor opens.
3. When inserting fields, you can use sliders and rulers to make fine adjustments to positioning.
4. Use sliders to specify field positions numerically.
5. Use rulers to visually confirm and adjust placement.

### Tableau Cloud
1. Click "Tooltip" on the marks card in a worksheet.
2. The tooltip editor opens.
3. Field insertion is possible, but precise placement adjustment with sliders and rulers is not available.
4. Only basic text editing functionality is available.

## Use Cases and Applications
- **Report Creation**: When you want to beautifully align information within tooltips
- **Dashboard Design**: Precise tooltip layout for improved user experience
- **Presentation Use**: Creating visually appealing tooltips

## Notes and Considerations
- This feature is only available in Tableau Desktop and is classified as an operationally important function.
- Since sliders and rulers are not available in Cloud, Desktop work is required for precise tooltip layouts.
- After publishing workbooks to Cloud, tooltip fine-tuning is not possible, so it's important to complete them in Desktop beforehand.
- While this feature may be implemented in Cloud in the future, no specific schedule has been announced at this time.
