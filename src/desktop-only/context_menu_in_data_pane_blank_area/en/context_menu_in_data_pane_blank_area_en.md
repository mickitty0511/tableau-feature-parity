## Feature Differences
Context menus in the blank areas of the data pane are only available in Tableau Desktop.

- **Desktop**: You can access various context menu options by right-clicking on blank areas of the data pane.
- **Cloud**: Right-clicking on blank areas of the data pane does not display context menus.

## Usage Instructions
### Tableau Desktop
1. Right-click on a blank area of the data pane (areas where no fields are placed).
2. A context menu appears allowing you to select available options.

![Context Menu in Desktop](./img/desktop/context_menu_blank_area_desktop_jp.gif)

### Tableau Cloud
1. Right-clicking on blank areas of the data pane does not display context menus.
2. This feature is not available in Cloud.

![No Context Menu in Cloud](./img/cloud/no_context_menu_blank_area_cloud_jp.gif)

## Notes and Considerations
- In Desktop, you can use context menus in blank areas of the data pane to manage and configure data sources.
- This feature is not currently implemented in Cloud.
- Details about specific menu options and usage examples will be added in the future.
