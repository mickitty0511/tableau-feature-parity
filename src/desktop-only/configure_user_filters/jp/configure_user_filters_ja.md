## 機能の違い
ユーザーフィルター設定は、Tableau Desktopでのみ利用可能です。

- **Desktop**: ユーザーフィルター機能が利用可能で、個人用のデータ表示をカスタマイズできます。
- **Cloud**: ユーザーフィルター設定機能は利用できません。

## 使用方法
### Tableau Desktop
1. ワークシートでフィルターを作成します。
2. フィルターカードを右クリックして「フィルターのカスタマイズ」を選択します。
3. 「ユーザーフィルター」タブを選択します。
4. ユーザーフィルターの設定を構成し、個人用のデータビューを作成します。


![Desktop ユーザーフィルター設定](./img/desktop/configure_user_filters_demo_desktop_jp.gif)

### Tableau Cloud
Tableau Cloudでは、ユーザーフィルター設定機能は利用できません。

## 使用例・ユースケース
- **個人化されたダッシュボード**: 各ユーザーが自分に関連するデータのみを表示するようにフィルターを設定
- **部門別データアクセス**: ユーザーの所属部門に基づいて適切なデータのみを表示
- **地域別レポート**: ユーザーの担当地域に応じたデータの自動フィルタリング

## 注意事項と考慮点
- この機能はTableau Desktopでのみ利用可能です。
- ユーザーフィルターは、パブリッシュ時にTableau Server/Cloudでも動作しますが、設定自体はDesktopで行う必要があります。
- ユーザーフィルターを効果的に使用するには、適切なユーザー権限とデータソースの設定が必要です。
- 今後のアップデートでCloudでの対応が予定されているかは未定です。
