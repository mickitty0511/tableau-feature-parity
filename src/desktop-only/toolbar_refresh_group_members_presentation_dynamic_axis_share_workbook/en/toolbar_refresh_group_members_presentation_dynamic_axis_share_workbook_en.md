## Feature Differences
Toolbar options including refresh, group members, presentation, dynamic axis, and workbook sharing are only available in Tableau Desktop.

- **Desktop**: Extended toolbar options are available including refresh, group members, presentation, dynamic axis, and workbook sharing
- **Cloud**: Only basic toolbar options are available (these advanced features are not included)

## Usage Instructions
### Tableau Desktop
1. Open Tableau Desktop
2. Create or open a workbook
3. The following options are available in the toolbar:
   - **Refresh**: Update data to the latest state
   - **Group Members**: Group selected items
   - **Presentation**: Start presentation mode
   - **Dynamic Axis**: Dynamic axis adjustment functionality
   - **Workbook Sharing**: Workbook sharing options

![Desktop Extended Toolbar Options](./img/desktop/extended_toolbar_options_desktop_jp.gif)

### Tableau Cloud
1. Access Tableau Cloud
2. Open a workbook
3. Only basic toolbar options are available

![Cloud Basic Toolbar](./img/cloud/basic_toolbar_cloud_jp.png)

## Use Cases and Applications
- **Data Refresh**: Update visualizations with the latest data
- **Grouping**: Group related data items to simplify analysis
- **Presentation**: Full-screen display for meetings and presentations
- **Dynamic Axis**: Automatic axis adjustment in response to data changes
- **Sharing**: Share workbooks with team members

## Notes and Limitations
- These advanced toolbar features are only available in Tableau Desktop
- Tableau Cloud is limited to basic toolbar functionality
- For more detailed feature descriptions, please refer to Tableau's official documentation
- Some features may become available in Tableau Cloud through future updates
