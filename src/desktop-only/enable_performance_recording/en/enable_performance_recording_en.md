# Performance Recording

## Feature Differences

Performance recording functionality is available only in Tableau Desktop and is not available in Tableau Cloud.

- **Desktop**: Performance recording feature is available from the Help menu
- **Cloud**: Feature is not available

## Usage Instructions

### Tableau Desktop
1. Open the Help menu
2. Select "Performance Recording" to start recording performance
3. When recording is stopped, performance data is displayed

![Performance Recording (Desktop)](./img/desktop/enable_performance_recording_desktop_jp.png)

### Tableau Cloud
Performance recording functionality is not available in Tableau Cloud.

## Notes and Constraints

- **Desktop**: Performance recording feature allows detailed analysis of workbook performance
- **Cloud**: This feature is not available due to server environment constraints
- Please use Tableau Desktop when performance analysis is required
