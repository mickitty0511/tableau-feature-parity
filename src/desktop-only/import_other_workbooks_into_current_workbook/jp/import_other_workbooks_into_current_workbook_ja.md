## 機能の違い
他のワークブックを現在のワークブックにインポートする機能は、Tableau Desktopでのみ利用可能です。

- **Desktop**: 他のワークブックのワークシート、ダッシュボード、ストーリーを現在のワークブックにインポートできます。
- **Cloud**: この機能は利用できません。

## 使用方法
### Tableau Desktop
1. 現在のワークブックでメニューバーから「ファイル」を選択します。
2. 「インポート」オプションを選択します。
3. インポートしたいワークブックファイル（.twb または .twbx形式）を選択します。
4. インポートするワークシート、ダッシュボード、ストーリーを選択します。
5. 「OK」をクリックしてインポートを実行します。

### Tableau Cloud
Tableau Cloudでは、他のワークブックを現在のワークブックに直接インポートする機能は提供されていません。

## 使用例・ユースケース
- **複数のワークブックの統合**: 異なるプロジェクトで作成したワークシートを1つのワークブックにまとめる場合
- **テンプレートの再利用**: 標準的なダッシュボードテンプレートを新しいワークブックに取り込む場合
- **作業の効率化**: 既存のワークシートをベースに新しい分析を行う場合

## 注意事項・考慮点
- **データソース依存性**: インポートされるワークシートが参照するデータソースが現在のワークブックに存在しない場合、データソースの再設定が必要になります。
- **計算フィールドの競合**: 同名の計算フィールドが存在する場合、名前の重複が発生する可能性があります。
- **フォーマットの継承**: インポートされるワークシートのフォーマット設定も一緒に取り込まれます。
- **作業効率の差**: この機能がCloudで利用できないため、複数ワークブックの統合作業においてDesktopとCloudで作業効率に大きな差が生じます。

## 将来の展望
この機能はTableau Cloudでの作業効率向上において重要な機能であり、今後のアップデートでCloud版への実装が期待されます。
