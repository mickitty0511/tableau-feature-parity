## Feature Differences
Story formatting functionality is only available in Tableau Desktop.

- **Desktop**: Detailed formatting settings for stories are available
- **Cloud**: Basic story creation is possible, but advanced formatting features are not available

## Usage Instructions
### Tableau Desktop
1. Create or select a story tab
2. Access the story formatting menu
3. Various formatting options can be configured

![Desktop Story Formatting Menu](../jp/img/desktop/configure_story_format_desktop_jp.png)
![Desktop Story Formatting Panel](../jp/img/desktop/configure_story_format_panel_desktop_jp.png)

### Tableau Cloud
1. Basic story tab creation is possible
2. However, advanced formatting features are not available

![Cloud Basic Story Menu](../jp/img/cloud/configure_story_format_cloud_jp.png)

## Use Cases and Applications
- Creating high-quality storyboards for presentations
- Design adjustments to align stories with brand guidelines
- Achieving more visually compelling storytelling

## Notes and Considerations
- Formatting settings created in Desktop may not be fully reproduced in Cloud
- For advanced story formatting requirements, working in Desktop environment is recommended
- Equivalent functionality may potentially be provided in Cloud environment in the future
