## 機能の違い
Tableau Desktopでは、Tableau Cloudよりも多くのキーボードショートカットが利用可能で、作業効率を大幅に向上させることができます。

- **Desktop**: 全画面モード切り替え、行列の入れ替え、セルサイズ調整、ビューでのデータ更新など多数の追加ショートカットが利用可能
- **Cloud**: 基本的なショートカットのみ利用可能で、Desktop固有の機能に関連するショートカットは使用不可

## 使用方法

### Tableau Desktop固有のショートカット（Windows）

**ワークブック・シート・ファイル管理:**
- `F11`: 全画面モードのオンとオフを切り替える
- `F12`: ワークブックを最後に保存した状態に戻す

**データ操作:**
- `F9`: ビューでデータ更新を実行する
- `F10`: 自動データ更新のオンとオフを切り替える

**ビュー作成:**
- `Ctrl + W`: 行と列を切り替える
- `Ctrl + L`: ビュー下部の列ラベルの向きを反転させる

**行・列・セルサイズ調整:**
- `Ctrl + B`: セルサイズを小さくする
- `Ctrl + Shift + B`: セルサイズを大きくする

### Tableau Desktop固有のショートカット（Mac）

**ワークブック・シート・ファイル管理:**
- `Control+Command+F`: 全画面モードのオンとオフを切り替える
- `Option+Command+E`: ワークブックを最後に保存した状態に戻す

**データ操作:**
- `Shift+Command+0`: ビューでデータ更新を実行する
- `Option+Command+0`: 自動データ更新のオンとオフを切り替える

**ビュー作成:**
- `Control+Command+W`: 行と列を切り替える

**行・列・セルサイズ調整:**
- `Command+B`: セルサイズを小さくする
- `Command+Shift+B`: セルサイズを大きくする

### 共通で利用可能なショートカット

以下のショートカットは両方のプラットフォームで利用可能です：

**基本操作:**
- 新しいワークブック作成、ファイル保存、印刷
- データソース接続、データ更新
- 元に戻す、やり直し
- フィールドの配置、マークの選択
- ダッシュボードグリッドの切り替え

## 使用例・活用場面

**効率的なワークフロー:**
- `Ctrl + W` (Windows) / `Control+Command+W` (Mac) を使用して、データの行と列を素早く入れ替えて最適な表示を見つける
- `F9` (Windows) / `Shift+Command+0` (Mac) でリアルタイムデータを手動更新
- `Ctrl + B` / `Command+B` でセルサイズを細かく調整して表示を最適化

**プレゼンテーション:**
- `F11` (Windows) / `Control+Command+F` (Mac) で全画面モードに切り替えてプレゼンテーション表示

## 注意事項・考慮点

- **Desktopの優位性**: Desktop版では生産性向上のための多数の追加ショートカットが利用可能
- **プラットフォーム固有機能**: 全画面モード、セルサイズ調整、行列入れ替えなどの機能はDesktop固有のため、これらに関連するショートカットはCloudでは利用不可
- **作業効率への影響**: Desktop固有のショートカットを活用することで、特に大量のデータ処理やダッシュボード作成において作業時間を大幅に短縮可能
- **キーボード操作の習慣**: Desktopで効率的なキーボード操作に慣れているユーザーは、Cloudでは一部の操作をマウスで行う必要がある
