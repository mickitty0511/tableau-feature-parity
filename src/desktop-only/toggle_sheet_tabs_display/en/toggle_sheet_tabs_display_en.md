## Feature Differences
Sheet sorter, filmstrip, and tab display options are only available in Tableau Desktop.

- **Desktop**: Sheet sorter, filmstrip view, and tab display options are available to streamline navigation between sheets within workbooks.
- **Cloud**: These advanced sheet navigation features are not available; only basic sheet tabs are displayed.

## Usage Instructions
### Tableau Desktop
1. **Sheet Sorter Feature**:
   - Right-click in the sheet tab area at the bottom of the workbook and select "Sheet Sorter"
   - All sheets are displayed in a list and can be reordered using drag & drop

2. **Filmstrip View**:
   - Right-click in the sheet tab area at the bottom of the workbook and select "Filmstrip"
   - Visual navigation is possible with thumbnail display of sheets

3. **Tab Display Options**:
   - Right-click in the sheet tab area at the bottom of the workbook and select display options
   - Sheet tab display methods can be customized

### Tableau Cloud
1. Only basic sheet tabs are displayed
2. Navigation between sheets is only possible by clicking tabs

## Use Cases
- **Large Workbooks**: Efficient navigation in workbooks containing many sheets
- **Sheet Management**: Reordering and organizing sheets
- **Presentations**: Visual sheet confirmation with filmstrip view

## Notes and Considerations
- Sheet sorter, filmstrip, and tab display options are exclusive features of Tableau Desktop
- Only basic sheet tab functionality is available in Tableau Cloud
- When working with workbooks containing many sheets, Desktop environment usage is recommended
- Functionality expansion on the Cloud side may be planned for future updates
