## Feature Differences
The bookmark feature for important worksheets is only available in Tableau Desktop.

- **Desktop**: You can bookmark worksheets for quick access
- **Cloud**: Bookmark functionality is not available

## Usage Instructions
### Tableau Desktop
1. Open the worksheet you want to bookmark
2. Select **Window (W)** from the menu bar
3. Select the **Bookmark (B)** option
4. Bookmarked worksheets can be quickly accessed later

![Desktop Bookmark Feature](./img/desktop/bookmark_feature_menu_desktop_jp.png)

### Tableau Cloud
Tableau Cloud does not provide bookmark functionality.

## Use Cases
- Quick access to frequently referenced important worksheets
- Efficient navigation in large workbooks containing multiple worksheets
- Managing worksheets commonly used during work

## Notes and Considerations
- This feature is only available in Tableau Desktop
- Bookmarks are saved as local settings
- Bookmark information is not shared when sharing workbooks with other users
