## Feature Differences

Rearranging shelves, parameters, and legends on the worksheet edit screen is only available in Tableau Desktop.

- **Desktop**: You can freely rearrange shelves, parameters, and legends using drag & drop
- **Cloud**: Layout is fixed and cannot be changed

## Usage Instructions

### Tableau Desktop
1. Open the worksheet edit screen
2. Click and drag shelves, parameters, or legends
3. Drop them in the desired position to change their arrangement

![Rearrangement in Desktop](../jp/img/desktop/arrange_workspace_layout_desktop_jp.gif)

### Tableau Cloud
1. Open the worksheet edit screen
2. Layout is fixed and drag & drop rearrangement is not possible

![Fixed Layout in Cloud](../jp/img/cloud/arrange_workspace_layout_cloud_jp.gif)

## Use Cases and Applications

- **Workspace Optimization**: Position frequently used shelves in easily accessible locations
- **Custom Layout**: Adjust layout according to project or work style
- **Efficient Work**: Improve work efficiency by placing frequently used elements nearby

## Notes and Limitations

- This feature is only available in Tableau Desktop
- In Tableau Cloud, layout is fixed and arrangement cannot be changed
- Arrangement changes are saved within the workbook and will be reflected when opened next time
- Some shelves and panels may not be rearrangeable
