## Feature Differences
The Analytics cycle fields feature is only available in Tableau Desktop.

- **Desktop**: You can use the cycle fields feature from the Analytics pane.
- **Cloud**: This feature is not available.

## Usage Instructions
### Tableau Desktop
1. Open the Analytics pane in worksheet view.
2. You can see the cycle fields option in the Analytics pane.
3. You can use this feature to cycle through fields.

Desktop example:

![Desktop Analytics Cycle Fields](./img/desktop/analytics_cylcle_option_desktop_jp.png)

### Tableau Cloud
1. Open the Analytics pane in worksheet view.
2. The cycle fields option is not displayed in Cloud.

Cloud example:

![Cloud No Analytics Cycle Fields](./img/cloud/no_analytics_cycle_option_cloud_jp.png)

## Use Cases
- In Desktop, you can use the Analytics cycle fields feature to enable cyclical display of fields in data analysis.
- This feature allows efficient switching and comparative analysis between multiple fields.

## Notes and Limitations
- This feature is currently only available in Tableau Desktop.
- Equivalent functionality is not provided in Tableau Cloud.
- For future Cloud support, please check Tableau's official update information.
