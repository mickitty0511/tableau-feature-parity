## Feature Differences
The toggle toolbar/status bar display functionality is only available in Tableau Desktop.

- **Desktop**: You can toggle the visibility of toolbars and status bars from the Window menu.
- **Cloud**: This functionality is not available.

## Usage Instructions
### Tableau Desktop
1. Click the "Window" tab in the menu bar.
2. You can select show/hide options for toolbars and status bars from the display options.

![Desktop Display Options](./img/desktop/window_display_options_desktop_jp.png)

### Tableau Cloud
This functionality is not available in Tableau Cloud.

## Use Cases and Applications
- Hide toolbars when you want to maximize screen space
- Customize workspace to improve work efficiency
- Hide unnecessary elements during presentations

## Notes and Limitations
- This functionality is only available in Tableau Desktop
- Screen display customization options are limited in Tableau Cloud
- When toolbars are hidden, access to some functions may be restricted
