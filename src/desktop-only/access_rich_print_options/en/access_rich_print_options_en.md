## Feature Differences
Rich print options from the file tab are only available in Tableau Desktop.

- **Desktop**: You can access detailed print options from the file tab with advanced print settings available
- **Cloud**: Rich print options are not available

## Usage Instructions
### Tableau Desktop
1. Open a workbook
2. Click on the file tab
3. You can select detailed settings from print options

![Print Options File Menu](../jp/img/desktop/access_rich_print_options_desktop_jp.png)
![Print Options Demo](../jp/img/desktop/access_rich_print_options_demo_desktop_jp.gif)

### Tableau Cloud
Rich print options from the file tab are not available in Tableau Cloud. Only basic print functionality is provided.

## Use Cases and Applications
- High-resolution print settings
- Custom paper size configuration
- Detailed print layout adjustments
- Creating professional print outputs

## Notes and Limitations
- This feature is only available in Tableau Desktop
- Tableau Cloud only provides basic print functionality
- Consider using Tableau Desktop when detailed print settings are needed

## Future Outlook
Support for rich print options in Tableau Cloud may be improved in future updates.
