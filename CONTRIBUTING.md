# Contributing

This project is not currently accepting external contributions.

Issues and pull requests are not part of the public contribution workflow yet. If that changes, this file will be updated with the intake policy, license checks, review expectations, and maintenance responsibilities.

## Project Support

Although external contributions are closed, sponsorship is welcome. Sponsorship helps reserve time for Tableau version checks, screenshot refreshes, article maintenance, and keeping Cloud / Desktop differences easy to find when teams need to make product and workflow decisions.

## Sponsorship Boundary

Sponsorship is project support, not a purchase of editorial control or guaranteed coverage. Public sponsor names may be listed when the sponsorship tier includes listing and the name is appropriate for a public project page.
