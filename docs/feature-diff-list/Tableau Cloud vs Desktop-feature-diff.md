Tableau Cloud vs. Tableau Destop ワークブック編集コマンド差分

Tableau Cloudにない ・ Tableau Desktopにある
・フィールドの既定のプロパティに
文字列型フィールドには色、数値形式、コメント、形状
数値フィールドはそれに加えて集計、次を使用して合計がある
・データペインで「未使用のフィールドをすべて非表示」がコマンドがあるので、使用しているフィールドのみをデータペイン上で表示できる
・計算フィールドや各ワークシートで使用しているフィールドを別のフィールドへ一括で差し替える「参照の置換」がある
・会計年度設定ができる
・日付のプロパティからデフォルトの会計年度開始月の設定や週の開始、日付形式を指定できる
・カスタム形状が使える
・軸をクリックしたら軸とペインの書式設定(既定、合計や総計、特殊な値(例:NULL)の設定)ができる
・カスタムカラーパレットが使える
・シート上で選択したデータのコピーができる
・ドロップラインがある
・合計と総計のラベルを書式設定から変更できる
・シェルフの空白エリアで右クリックすると、シェルフのクリアや新しい計算といったコマンドを含むコンテキストメニューが表示される
・ラベルマークからテキストの配置(左寄せ/右寄せ/真ん中寄せ)の設定などラベルの外観の設定がある
・並び替えや色の設定を引き継ぐデータソースの差し替えコマンド Tableau サーバー > サイトパスがある
・分析タブに「表のレイアウト」があるので、空の行、列を表示できる。また詳細からデザイン調整オプションが多い
・ショートカットキーが多い
・パブリッシュ時に、選択したプロジェクト内にあるワークブックをリストで表示、選択できる(そのため、上書きしやすい)
・パブリッシュ時に、説明やタグ、パーミッション、Cloud上に表示するシートを選択、その他のオプションを更新できる ※Tableau Cloudは、Cloud上に表示するシートは一つずつ、シート名を右クリックして「パブリッシュ」オプションをつけたり外す必要があり手間取る
・マップタブから背景イメージを設定できるなど、マップタブの設定が豊富
・セルのサイズを細かく設定できる
・ツールヒントにフィールドの配置を補助する「スライダー」と「ルーラー」がある
・ストーリーの書式設定ができる
・ストーリーの戻る/進むボタンの表示/非表示ができる
・注目したいワークシートを見るブックマーク機能がある ※Tableau Cloudならお気に入りと同じ
・アナリティクスに予測、クラスター、箱ひげ図がある
・データペイン内の空白エリアで右クリックしたら、フィールドの貼り付けやフォルダの作成などのコンテキストメニューが出るので、操作しやすい
・Ctrl + 左クリックでドラッグのショートカットキーでシートを複製できる
・ワークシートの書式設定のコピー、貼り付けができる
・リファレンスライン、注釈、ドロップライン、タイトルとキャプション、フィールドラベルのワークブックのデフォルトの書式設定を書式設定タブから指定できる
・ワークシートの編集画面上で空白エリア上で右クリックすると、各シェルフ、必要な凡例やパラメータ、キャプション、サマリなどの表示/非表示を選択できる(コンテキストメニュー表示がある) ※Tableau Cloudはワークシート編集画面上部二表示されているツールバーのアイコンから操作できるが、シェルフや凡例は選択できない
・ツールバー、ステータスバーの表示の切り替えができる(ウィンドウタブから)
・ワークシートの編集画面上でシェルフやパラメータ、凡例の配置を変更できる
・線グラフにしたときに、マーカーオプションから線のデザインを指定できるので、データ地点ごとに点を表示できるデザインが可能
・カスタムテーマのインポートができる 現時点ではバージョン2025.1のみ
・ユーザフィルタの設定が可能
・凡例から「選択したアイテムをハイライト」を有効化すると、「ハイライト色をパレットに割り当てる」オプションがある
・ブレンドの設定オプションがある
・分析タブ > 「非表示のデータを表示」コマンドから、凡例や軸選択で右クリックなどから値を「非表示」としたデータを再表示できる
・接続中のデータソースの全データをローカルPCにcsvやhyper形式で落とせる
・行や列ペイン、フィルターペイン、マークカード上などでピルを複数選択できる ※Tableau Cloudはデータペインからの複数選択のみ可
・行と列にメジャーフィールドを入れたときに、サイズから手動/固定を設定して表示をカスタマイズできる
・文字列フィールドをデータソースペーンで右クリックしたときに、変換コマンドがある(変換コマンドには分割、カスタム分割、日付の作成、ピボット操作がある)
・シートソーター、フィルムストリップ、タブの表示のシート表示のオプション設定がある
・ユーザ切り替えオプションを使って、どのユーザがどのデータが見えるかの差分を確認できる
・書式設定 > ワークブックテーマオプションがある
・ツールバーに更新の実行、メンバーのグループ化、プレゼンテーション、動的に範囲の変わる軸に設定、ワークブックを他のユーザに共有がある
・他のワークブックの選択したシートをコピー、今作業しているワークブックへ貼り付けできる
・他のワークブックを作業中のワークブックへインポートができる
・シート1つをワークブックファイルとしてエクスポートできる
・ファイルタブから、ワークブックのエクスポート方法にワークブックファイル名にバージョン名つけるがある
・ファイルタブ > 印刷オプションが豊富
・分析 > フィールドのサイクル表示がある

Tableau Cloudにある ・ Tableau Desktopにない
・サイズマークからサイズを入力できる
・ダッシュボードのレイアウト > 項目の階層 で各アイテムをドラッグで移動できる
・テキストオブジェクトにURLリンクとその表示名を変更(ハイパーリンク機能が利用)できる
・ワークシート名(ダッシュボード・ストーリー含む)を変えてパブリッシュしても、ビューのURLリンクが変わらない(そのため、Tableau Cloudやブラウザなどで登録したビューのお気に入りのリンクが壊れない)
・パブリッシュ時に、プロジェクト名を検索できる
・地理的役割を設定していない文字列型でも地理的役割 > 次から作成のオプションがある ※Tableau Desktopは地理的役割を割り当てないと表示されない
・メジャーネームを右クリックすると表示されるコンテキストメニューに「説明」が表示される
・ツールバーに合計オプションの設定、ワークブックの書式設定、ダウンロードがある
・ワークブックの下書き自動保存がある(ただし、ワークブックの容量5MBまで)

どちらもあるが、異なる
・データソースの置換コマンド
Tableau Desktop: データソース名を右クリックしたコンテキストメニューからすぐにアクセスできる 
Tableau Cloud: データソースタブから該当のデータの右上にある「▼」をクリックして置換する。クリック操作が多い

・フォント、配置、網掛け、枠線、線の書式設定のレイアウト
Tableau Desktop: アイコンごとに管理。切り替えて作業できる
Tableau Cloud: 1画面でセクションごとに分かれている。画面いっぱいにテキストが埋まっており情報量が多く作業しにくい

・ダッシュボードの書式設定へのアクセス
Tableau Desktop: ダッシュボードタブ > 書式設定
Tableau Cloud: 書式設定タブ > ダッシュボード

・メジャーネームを右クリック時に表示されるコンテキストメニューから「別名」の編集画面に表示されるフィールド
Tableau Desktop; ワークシートで使用しているものに限定して表示される
Tableau Cloud; すべてのメジャーフィールドが表示される

・凡例・パラメータ・フィルターカードの書式設定にアクセス時
Tableau Cloud: 1画面でタブ切り替えでこのカードのみ、すべてのカードの書式設定を適用するシームレス操作となっている
Tableau Desktop: このカードのみ、すべてのカードのいずれかを選択して、選択した片方だけを書式設定をするような断続的な操作となっている

・ツールバーのワークシートのクリアで選択できるコマンド
Tableau Desktop: 手動サイズ変更のクリア、軸範囲のクリア、フィルターのクリア、並べ替えのクリア、コンテキストのクリア
Tableau Cloud: ワークシートのクリアのみ

・ダッシュボードとストーリーのイメージのエクスポート
Tableau Cloud: Creatorライセンスはワークブック編集時に表示されるツールバー 
View・Explorer・Creatorライセンスはビュー閲覧時の右上にあるダウンロードボタンから(ダウンロード権限必要)
Tableau Desktop: 右クリックして表示されるコンテキストメニュー OR 「ダッシュボード」・「ストーリー」タブ  > イメージのエクスポートなど

・データペインで複数のフィールド選択時に右クリックして表示されるコンテキストメニュー
Tableau Desktop: 非表示のほか複数あり
Tableau Cloud: 非表示のみ

・データの表示コマンドの出現場所
Tableau Desktop: 
ワークシート上の空白エリアを右クリックして表示されるコンテキストメニュー 
データ選択時に右クリックして表示されるコンテキストメニュー
データペインのフィールド検索欄の右横
データ > [接続中のデータソース名] > データの表示
データペイン内のデータソース名を右クリックして表示されるコンテキストメニュー

Tableau Cloud: 
ワークシート上の空白エリアを右クリックして表示されるコンテキストメニュー
データ選択時に右クリックして表示されるコンテキストメニュー
