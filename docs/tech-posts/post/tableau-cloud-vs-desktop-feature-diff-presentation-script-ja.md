# Tableau Cloud vs Desktop 機能差分紹介 発表スクリプト（日本語）

## Slide 1: Tableau Cloud vs Desktop 機能差分紹介
今日は、Tableau Cloud と Tableau Desktop の機能差分を、3つの具体例から紹介します。

ここで扱う差分は、単なる「できる・できない」の一覧ではありません。実際の作業で、どちらの環境を使うべきかを判断するための材料として見ていきます。

## Slide 2: 目的と経緯
このプロジェクトは、Cloud と Desktop の両方を使うユーザーを支援する中で感じた課題から始まりました。

Cloud ではできるけれど Desktop ではできないことがあります。逆に Desktop でしかできないこともあります。さらに、同じような機能名でも、できる範囲や操作感が違う場合があります。

その差分を記録しておくことで、今の作業判断を助けるだけでなく、将来的には生成AIが Tableau Dashboard Builder を支援するときの知識としても活用できるようにします。

## Slide 3: 今回取り上げる3つの差分
今回は3つの差分を取り上げます。

1つ目は、Cloud で使えるダッシュボードレイアウト階層のドラッグアンドドロップです。2つ目は、Desktop で使えるツールチップ配置のスライダーとルーラーです。3つ目は、Desktop で使える参照の置換です。

大きく見ると、Cloud はブラウザ上の直感的な編集に強みがあり、Desktop は精密調整やワークブック保守に強みがあります。

## Slide 4: #12 Cloud-only レイアウト階層の整理
1つ目は、Cloud-only の差分です。

Tableau Cloud では、ダッシュボードのレイアウト階層パネル内で、項目を直接ドラッグアンドドロップして並べ替えられます。階層構造を見ながら項目順やコンテナ内の配置を調整できるため、複雑なダッシュボードを整理するときに便利です。

一方で Desktop では、レイアウト階層内で直接移動する操作はできません。ダッシュボード上で直接操作する必要があるため、構造を見ながら整理したい場面では Cloud の方が効率的です。

## Slide 5: #22 Desktop-only ツールチップ配置を精密に調整
2つ目は、Desktop-only の差分です。

Tableau Desktop では、ツールチップを編集するときにスライダーとルーラーを使い、フィールド配置を細かく整えられます。レポートやプレゼン用途で、ツールチップ内の情報を読みやすく見せたい場合に有効です。

Cloud でも閲覧や軽微な編集はできますが、ツールチップの見え方まで作り込みたい場合は、公開前に Desktop で仕上げておく方が安心です。

## Slide 6: #27 Desktop-only 参照フィールドを一括置換
3つ目も Desktop-only の差分です。

「参照の置換」は、計算フィールドやワークシートで使っているフィールドを、別のフィールドへまとめて置換できる機能です。データソース変更、フィールド名変更、似た役割のフィールド統合などで役立ちます。

多数の計算フィールドやワークシートを含むワークブックでは、保守作業を大きく効率化できます。ただし影響範囲が広いため、実行前にはバックアップとデータ型の確認が必要です。

## Slide 7: まとめ 作業内容で使い分ける
まとめると、機能差分は作業効率、保守性、公開後の修正コストに直結します。

Cloud は、共有後の編集、ダッシュボード構造の整理、ブラウザ上での共同作業に向いています。Desktop は、公開前の精密調整、大規模修正、ワークブック保守に向いています。

作業前に、Cloud で足りる範囲と Desktop に戻すべき範囲を切り分けておくことで、戻り作業や手戻りを減らせます。
