## 使用上の注意 / Usage Notes

1. **用語の統一**: プロジェクト内では統一した用語を使用してください
2. **バージョン差異**: Tableau のバージョンにより用語が変更される場合があります
3. **地域差異**: 日本語UIと英語UIで表示が異なる場合があります
4. **更新**: このドキュメントは定期的に更新される予定です
