## Feature Difference
The context menu that appears when right-clicking after selecting multiple fields in the data pane differs between Tableau Desktop and Tableau Cloud.

## Additional Notes
- **Tableau Desktop**: Multiple commands are available in addition to "Hide".
- **Tableau Cloud**: Only the "Hide" command is available.
